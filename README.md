# Financial Habit Builder & Wealth Growth Tracker

Full-stack app to build financial habits and track wealth growth.

## Features
- User authentication (JWT)
- Income & Expense tracking
- Financial Habit Tracker with streaks
- Savings Goals
- Wealth / Investment tracking + Net Worth
- Admin Panel
- Responsive UI with Tailwind CSS

## Tech Stack
- Frontend: React 18 + Vite + Tailwind CSS + Chart.js
- Backend: Node.js + Express
- Database: JSON file (easy to swap to MongoDB)

## How to Run Locally

### Backend
```bash
cd backend
npm install
npm run dev
```
Runs on http://localhost:5000

### Frontend
```bash
cd frontend
npm install
npm run dev
```
Runs on http://localhost:5173
